# Contributing to Trail Journal

Thanks for your interest! Trail Journal is a small project, so contributing is simple.

## Ways to help

- **Test it on your own recordings** and share what BirdNET and Gemma produced (bird list and journal entry).
- **Improve the Marathi.** If the model's Marathi sounds wrong or unnatural, suggest a better prompt.
- **Add another language.** The prompt can be changed to write the journal in any language Gemma supports.
- **Fix bugs or improve the script.** See the ideas in the Roadmap section of the README.
- **Improve the docs.** Typos, unclear steps, and missing screenshots all count.

## How to contribute

1. **Fork** the repository and clone your fork.
2. Create a branch: `git checkout -b my-change`
3. Make your change and **run the script on a short recording** to check it still works.
4. Commit with a clear message and push: `git add .`, `git commit -m "Describe what you changed"`, `git push origin my-change`
5. Open a **Pull Request** and explain what you changed and why.

## Guidelines

- Keep changes small and focused. One idea per pull request.
- Do not commit audio recordings you do not have the right to share. Credit the source (for example xeno-canto) if you add a sample.
- Do not add API keys, tokens, or personal data.
- If you change the prompt, include a short before/after example of the output.
- Be kind and respectful. Beginners are welcome.

## Reporting problems

Open an **Issue** and include:

- What you ran (the command)
- What you expected
- What happened (paste the error message)
- Your OS and Python version
